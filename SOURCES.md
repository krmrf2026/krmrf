# Источники и доказательные копии

## Что делает система

`npm run check` сканирует внешние ссылки внутри публикаций и обновляет:

- `data/sources.json` — реестр источников;
- `sourceIds` в `data/pages.json` — связь публикации с источниками;
- `data/source-preservation-queue.json` — очередь важных источников, которые ещё не сохранены.

Реестр не утверждает, что источник независим или достоверен. Он фиксирует происхождение ссылки и состояние её сохранения.

## Когда нужна локальная копия

В первую очередь сохраняются допустимые копии источников для:

- досье;
- оценок фронта;
- практических памяток, основанных на нормативных документах;
- материалов, где исчезновение страницы разрушит доказательную цепочку.

Не сохраняйте материалы с нарушением закона, лицензии, приватности или достоинства пострадавших. В таких случаях укажите точный архивный URL, библиографическое описание или причину невозможности сохранения.

## Как сохранить файл

1. найдите источник в `data/source-preservation-queue.json`;
2. законно получите PDF, изображение, видео, HTML-снимок или иной файл;
3. выполните:

```bash
npm run source:capture -- src-xxxxxxxxxxxx /путь/к/файлу.pdf
```

При наличии точного архивного снимка:

```bash
npm run source:capture -- src-xxxxxxxxxxxx /путь/к/файлу.pdf https://точный-архивный-url
```

Команда:

- копирует файл в `data/sources/files/<source-id>/`;
- фиксирует дату доступа;
- рассчитывает SHA-256;
- меняет статус на `preserved`.

После этого выполните `npm run check`.

## Требования к доказательной записи

Для ключевого источника должны быть понятны:

- кто опубликовал;
- исходный URL;
- дата доступа;
- локальная или архивная копия;
- SHA-256 локального файла;
- какие публикации KRM РФ на него ссылаются;
- ограничения и причина доверия или недоверия.

Сам факт наличия ссылки не превращает утверждение в подтверждённое.
