# KRM РФ — отчёт о доводке r4

Дата: 20 июня 2026 года  
Исходная версия: `2026.6.20-r3`  
Подготовленная версия: `2026.6.20-r4`

## Итог

Все 17 технических и системных задач повторного аудита обработаны. Внешний вид и мобильная система r3 сохранены. Тексты публикаций и действующие URL не переписывались, кроме исправления служебных метаданных, семантики и канонического редиректа дублирующего индекса Кременной.

## Статусы задач

- `VAL-001` — выполнено: строгая проверка типов, дат, H1, JSON-LD, canonical, разделов, источников, изображений, sitemap и карты; четыре негативных теста.
- `VER-001` — выполнено системно: `dateModified`, видимая дата обновления, `revisionHistory`, sitemap, Atom и JSON-LD синхронизируются. Исторические даты не выдумывались.
- `SRC-001` — выполнена инфраструктура: реестр, связи `sourceIds`, приоритеты, очередь сохранения, локальная копия и SHA-256. Реальные копии требуют законного ручного получения.
- `BAK-001` — выполнено: release ZIP, `SHA256SUMS`, `.sha256`, fixity-проверка и `RECOVERY.md`.
- `PUB-001` — выполнено: `PUBLISHING.md` описывает `main`, production, проверку и откат.
- `MAP-001` — выполнено: неизменяемые снимки, manifest, SHA-256, provenance, архив карты и защита от перезаписи снимка.
- `ARC-001` — выполнено: отдельные фасеты типа, раздела и территории, комбинации, счётчики, URL, Back/Forward и сброс.
- `SEO-001` — выполнено: JSON-LD публикаций синхронизируется из `pages.json`.
- `A11Y-001` — выполнено: исправлены уровни заголовков и Escape; добавлены ARIA-состояния карты и подписи таблиц.
- `META-001` — выполнено: видимый раздел синхронизируется с каталогом.
- `IMG-001` — выполнено: добавлены 960w-файлы, проверка пар 480/960 и локальный генератор ImageMagick.
- `GUIDE-001` — выполнено: `reviewedAt`, `reviewAfter`, `reviewStatus`, видимое предупреждение и блокировка просроченного статуса.
- `SEARCH-001` — выполнено: fuzzy-подсказки и история браузера.
- `MAP-UX-001` — выполнено: `tileerror`, live-status и ARIA fullscreen.
- `TABLE-001` — выполнено: таблицы имеют `caption`.
- `IA-001` — выполнено: `/news/kremennaya/` перенаправляется на `/kremennaya/`, исключён из sitemap.
- `404-001` — выполнено: добавлены пути в поиск, архив, Кременную, справочник и оценки; HTTP 404 сохраняется.

## Проверки

- `npm run check` — проходит;
- `npm run test:negative` — четыре опасные ошибки корректно блокируются;
- `npm run test:smoke` — проходит;
- `npm run release` — создаёт проверенный архив;
- 46 публикаций и 64 HTML-страницы;
- карта имеет датированный снимок и SHA-256;
- 10 недостающих 960w WebP созданы;
- sitemap включает `/map/archive/` и не включает дублирующий индекс `/news/kremennaya/`;
- старых ссылок на версию r3 в HTML нет.

## Единственное намеренно не подделанное состояние

В `data/source-preservation-queue.json` находится очередь внешних источников, для которых ещё нет законно полученной локальной или точной архивной копии. Система показывает это честно. Заполнять `accessedAt`, `archiveUrl`, `localCopy` и SHA-256 фиктивными значениями запрещено.

## Финальная проверка сохранности содержания

- релизный ZIP проверен командой `unzip -t`;
- архив распакован в чистую папку;
- в восстановленной копии успешно выполнены `npm run fixity` и `npm run check`;
- программное сравнение всех 46 публикаций с исходным r3 подтвердило: основной текст публикаций не переписан; изменены только оболочка, метаданные, семантика, служебные статусы и доступность;
- SHA-256 релизного ZIP совпадает с отдельным файлом `.sha256`.
