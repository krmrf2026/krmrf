# KRM РФ

Статический HTML-first архив Кременной, ЛНР, восточного фронта, гражданских последствий, практических памяток и доказательных досье.

## Быстрый старт

```bash
npm run check
npm run serve
```

Документы:

- `PUBLISHING.md` — публикация и откат;
- `SOURCES.md` — реестр и сохранение источников;
- `RECOVERY.md` — резервирование и восстановление;
- `CHANGELOG.md` — изменения релизов.

Источник метаданных публикаций — `data/pages.json`. Готовое содержание остаётся в отдельных HTML-страницах и читается без JavaScript.
