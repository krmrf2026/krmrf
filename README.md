# KRM РФ — статический архив

Исходный репозиторий сайта `krmrf.ru`. Публичная версия собирается как статический HTML без CMS, базы данных и серверного приложения.

## Требования

- Node.js 22 (`.nvmrc`);
- npm 10+;
- ImageMagick нужен только при добавлении исходного изображения без производных версий 480/960 px.

## Быстрый старт

```bash
nvm use
npm ci
npm run qa
npm run serve:dist
```

`npm run qa` выполняет полную техническую проверку и создаёт чистую публичную папку `dist/`.

## Основные команды

| Команда | Назначение |
|---|---|
| `npm run build` | Синхронизирует метаданные, каталоги, карту, sitemap, Atom и поисковый индекс |
| `npm run qa` | Полный контроль качества и экспорт `dist/` |
| `npm run release` | Полный QA, негативные тесты, два ZIP-архива и контроль SHA-256 |
| `npm run content:check` | Проверяет, что техническая сборка не изменила тексты публикаций |
| `npm run content:lock` | Осознанно обновляет контрольные суммы текстов после редакционной правки |
| `npm run serve` | Локально обслуживает исходное дерево |
| `npm run serve:dist` | Локально обслуживает только публичную сборку |

## Структура

- `data/pages.json` — единые метаданные публикаций, включая отдельные SEO title/description;
- `data/content-integrity.json` — контроль целостности текстов;
- `data/zones.geojson` — текущая геометрия карты;
- `data/map-changes.json` — журнал последнего изменения карты;
- `data/rf_regions.json` — административные границы;
- `tools/` — сборка, проверки, экспорт и релиз;
- `dist/` — только публичные файлы, не хранится в Git;
- `SHA256SUMS` — создаётся только при релизе и не хранится в Git.

У проекта нет механизма сохранения источников, `sources.mjs`, `data/map/manifest.json` или каталога snapshots. Официальные ссылки, уже находящиеся в публикациях, остаются частью самих материалов.

## Гарантии QA

QA блокирует выпуск при битой ссылке, рассинхронизации карты, sitemap или метаданных, изменении текста технической сборкой, превышении бюджетов, неидемпотентной сборке, попадании служебных файлов в `dist` и других нарушениях. Полный перечень приведён в [QUALITY.md](QUALITY.md).
